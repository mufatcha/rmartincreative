Add it to Gmail
  1. Click Copy signature above (or select the signature and press Ctrl+C).
  2. In Gmail: Settings (gear) → See all settings → General → Signature → Create new.
  3. Paste with Ctrl+V. The logo comes along because it's already on rmartincreative.com.
  4. The QR code is a file on this computer, so Gmail drops it. Click where it was, then use the image button in the signature toolbar → Upload → choose qr-google-review-email.png from this folder. Pick the Small size, then link it to https://g.page/r/CRTfT7VsZx0vEBM/review.
  5. Set it as the default for new emails and replies, then Save Changes at the bottom.
