How to install in Gmail
  1. Open this file in Chrome (or any browser).
  2. Click and drag to select everything inside the dashed box below, then copy (Ctrl/Cmd + C).
  3. In Gmail: Settings (gear) → See all settings → General → Signature → Create new.
  4. Paste (Ctrl/Cmd + V) into the signature editor, name it, then click Save Changes at the bottom of the page.
